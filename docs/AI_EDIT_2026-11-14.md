# AI 수정 (영역 선택 → AI 편집) — 설계·사용·프라이버시 (2026-11-14)

## 한눈에
- **하는 일**: 사진에서 올가미/브러시/사각형/원형으로 영역을 고르고 "셔츠를 파란색으로", "이 물체 지워 줘" 처럼 말하면, **그 영역(+주변)만** AI 에 보내 고친 결과를 **선택 안쪽에만** 합성한다.
- **결과는 비파괴 레이어**: 잠긴 이미지 레이어(레이어 목록에 "AI 수정 · 문구")라서 숨기기·삭제·실행 취소·자동 복구가 된다. 적용 강도(투명도) 슬라이더, 변형 1~3장 중 고르기, 다시 생성 지원.
- **연결 방식**: OpenAI **Images API** `POST /v1/images/edits` (마스크 편집, `gpt-image` 계열). ChatGPT "플러그인"은 없고, ChatGPT 구독과 API 는 별개라 **내 API 키 + API 결제**가 필요하다.

## 왜 이 모델인가
| 질문 | 결정 |
|---|---|
| 텍스트 LLM(Claude·GPT-4 등)으로 되나? | 안 된다. 텍스트 모델은 픽셀을 만들지 못한다. **이미지 편집 모델**(마스크 지원)이 필요하다. |
| 기본 제공자 | **OpenAI gpt-image** — 마스크(투명=편집 영역) 편집 API 가 있고 한국어 문구도 이해한다. |
| 모델 이름 | 기본 **자동**: 내 키로 `GET /v1/models` 를 조회해 가장 새로운 `gpt-image-*`(mini·날짜 스냅샷보다 본 모델 우선)를 고른다 → 모델명이 바뀌어도 앱 수정이 필요 없다. 설정에서 직접 지정/자유 입력도 가능. |
| 다른 제공자 | `web/src/ai/openai.js`(요청/오류 매핑) + `AiClient`(호스트/경로 허용 목록) 두 곳만 늘리면 된다(예: Gemini 이미지 모델). 지금은 OpenAI 호환 서버(서버 주소 변경)까지 지원. |
| 조직 인증 | OpenAI 가 gpt-image 사용에 **조직 인증(Verify Organization)** 을 요구할 수 있다. 403 이면 앱이 안내 문구를 보여 준다. |

> 이 개발 환경에서는 OpenAI 공식 문서 사이트에 접속할 수 없어, 요청 필드는 공개된 사용 예와 커뮤니티 보고를 기준으로 구현했다(`model, prompt, image, mask, size, quality, n` + 응답 `data[].b64_json`). 모델명은 위처럼 자동 조회하고, 실패하면 오류 사유를 그대로 안내한다. **실제 키로는 아직 호출해 보지 못했다.**

## 데이터 흐름과 프라이버시
```
[사진] → 선택(마스크) → 요청 크롭(선택+주변) → image.png + mask.png + 문구
        → (JS) 업로드 청크 → (Java AiClient) HTTPS → api.openai.com → 결과 PNG
        → (JS) 선택 안쪽만 합성 → 이미지 레이어
```
- **보내는 것**: 선택 영역과 그 주변을 잘라 낸 PNG 1장, 편집 영역 마스크 PNG, 입력한 문구, 모델/크기/품질/개수. **전체 사진은 보내지 않는다.** 요청 중에는 "보낸 이미지(파란색 = 수정 영역)" 미리보기를 보여 준다.
- **첫 요청 전 동의**: 서버 호스트와 전송 내용을 알리고 동의를 받는다. 서버 주소가 바뀌면 다시 묻는다.
- **인터넷 권한(INTERNET)** 은 이 기능 때문에 추가됐다. 웹 화면(WebView)은 여전히 CSP + 외부 요청 403 이라 인터넷에 직접 접근할 수 없고, 네이티브 `AiClient` 만 나간다.
- **AiClient 제한**: 서버는 저장된 https 주소 하나(기본 `api.openai.com/v1`; IP·localhost·사내 도메인·포트·자격 증명·쿼리 거부), 경로는 `POST /images/edits`·`GET /models` 뿐, 리다이렉트 미추적, 요청 24MB/응답 96MB 상한, `Authorization` 은 네이티브에서만 붙임.
- **키 보관**: Android Keystore(AES-256-GCM)로 암호화해 앱 전용 저장소에 두고, 웹에는 `sk-…abcd` 힌트만 돌려준다. Keystore 를 못 쓰는 기기에서는 평문 저장 대신 저장을 거부한다. 설정에서 언제든 삭제할 수 있다.
- AI 수정을 한 번도 쓰지 않으면 앱은 인터넷을 쓰지 않는다.

## 동작 상세
- **선택**: 올가미(손 떼면 닫힘)·브러시·사각형·원형, 추가/빼기, 선택 되돌리기, 반전, 해제, 영역 넓히기/좁히기(±30), 경계 부드럽게. 확대/이동(핀치)하며 정밀하게 그릴 수 있다. 윤곽선은 marching squares 로 화면 해상도와 무관하게 선명하게 그린다.
- **요청 크롭**: 선택 영역 + 주변(좁게 15% / 보통 40% / 넓게 90%)을 제공 크기(1024², 1536×1024, 1024×1536 중 가장 가까운 비율)에 맞춰 **실제 주변 이미지로 넓혀서** 채운다(이미지 경계를 넘으면 흐린 확대본으로 채움). 영역은 보정·레이어까지 합성된 "보이는 그대로"를 작업 해상도로 다시 렌더해서 쓴다.
- **마스크**: 편집 영역 alpha=0. 모델이 경계를 자연스럽게 섞도록 선택보다 약간 넓힌다.
- **결과 합성**: 마스크는 모델에게 "안내"일 뿐이라 마스크 밖도 조금 바뀔 수 있다 → 결과를 **선택(+부드러운 경계) 안쪽에만** 쓴다. 또 선택 바로 바깥 고리 영역의 평균 색 차이로 결과의 밝기·색 drift 를 보정(±24)해 이음새를 줄인다.
- **한계**: 생성 해상도가 최대 1536px 라서 큰 영역은 덜 선명할 수 있다(작은 영역이 가장 좋음). 얼굴·글자·손의 정확도는 모델에 달렸다. 이후 보정(노출 등)을 바꿔도 AI 레이어는 그 시점의 결과다.

## 비용(참고)
- 요청당 장수(1~3)만큼 늘고, 품질(빠름/보통/고품질)이 높을수록 비싸다. 취소해도 이미 시작된 요청은 청구될 수 있다.
- gpt-image-1 출시 당시 공개 가격 기준 1장 대략 **$0.01(저품질) ~ $0.25(고품질·큰 크기)**. 모델·시점마다 다르니 OpenAI 가격표를 확인할 것.
