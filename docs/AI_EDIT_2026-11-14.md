# AI 수정 (영역 선택 → AI 편집) · AI로 이미지 만들기 — 설계·사용·프라이버시 (v1.5.0)

## 한눈에
- **하는 일**: 사진에서 올가미/브러시/사각형/원형으로 영역을 고르고 "셔츠를 파란색으로", "하늘을 맑게" 처럼 말하면, **그 영역(+주변)만** AI 에 보내(또는 문구만 보내) 만든 결과를 **선택 안쪽에만** 합성한다.
- **결과는 비파괴 레이어**: 잠긴 이미지 레이어(레이어 목록에 "AI 수정 · 문구")라서 숨기기·삭제·실행 취소·자동 복구가 된다. 적용 강도 슬라이더, 다시 생성 지원.
- **제공자 3종(설정에서 선택, 키는 제공자마다 따로 저장)**
  - **Cloudflare Workers AI** — 하루 무료. 사진을 보고 고치는 **편집**(FLUX.2) · 문구로 그리기(FLUX.1 schnell) · 한국어→영어 번역.
  - **Pollinations.ai** — **키 없이** 무료. 문구로 그리기만.
  - **ModelScope API-Inference** — 무료 체험 토큰. 문구로 그리기만(Qwen-Image 등).
- **v1.5.0 변경**: **OpenAI · OpenRouter 를 삭제**했다(요청: "Cloudflare 만 남기고 지워 줘"). 저장돼 있던 두 제공자의 키·설정·동의는 앱이 시작할 때 / 설정을 열 때 지운다. 되돌리려면 v1.4.0 APK 또는 git 이력(`2038374`)을 쓴다. 변형(여러 장)·품질 옵션·마스크 편집도 OpenAI 전용이라 함께 사라졌다.
- **사진을 보고 고치는 "편집"은 Cloudflare 만** 한다. Pollinations · ModelScope 는 사진을 보지 못하고 문구만으로 그리므로 영역 수정에서는 **"문구로 채우기"**(선택 안쪽을 새 그림으로 채움)로, 홈에서는 **"AI로 이미지 만들기"**로 쓴다. ModelScope 의 이미지 편집 모델은 공개 이미지 주소가 필요해(사진 전송 방식과 안 맞고, data URI 가능 여부는 확인 못 함) 넣지 않았다.
- 무료 모델 조사 결과는 [`FREE_IMAGE_MODELS_2026-11-15.md`](FREE_IMAGE_MODELS_2026-11-15.md).

## 시작하기
**Pollinations (설정할 것 없음)** — AI 도구 → 영역 수정 → AI 요청에서 "키 없이 쓰기: Pollinations", 또는 홈 "AI로 이미지 만들기"(키가 하나도 없으면 처음부터 Pollinations 가 선택돼 있다).
- 문구는 **주소(URL)에 담겨 전송**돼 서버 기록에 남을 수 있다 → 개인 정보는 적지 말 것. 영어 문구가 가장 잘 그려진다. 결과는 JPEG 이고 작은 로고가 붙을 수 있다.
- **한도(429/402)**: "한 번에 한 장, 약 45초 간격" 으로 안내한다. "다시 만들기"는 잠시 뒤에.

**Cloudflare (꾸준히 무료)**
1. dash.cloudflare.com 에 무료 가입(카드 불필요).
2. **계정 ID**: 대시보드 주소의 32자리 값(주소째 붙여 넣어도 32자리를 찾는다).
3. **API 토큰**: My Profile → API Tokens → Create Token → "Workers AI" 템플릿.
4. 앱: 설정 → "Cloudflare · 하루 무료" → 계정 ID·토큰 입력 → 연결 테스트.
- 무료 한도는 하루 10,000 Neurons(UTC 자정 초기화). 초과하면(Cloudflare 오류 3036) "오늘의 무료 사용량을 모두 썼어요" 로 안내한다.
- **주의**: Cloudflare 는 2026-07 부터 일부 모델을 무료 플랜에서 막았다(403, 내부 오류 5035 — 공지된 모델은 Kimi·GLM 등 **텍스트** 모델). FLUX.2 가 무료 계정에서 되는지는 확인하지 못했다. 막히면 앱이 "유료 플랜 필요" 로 안내하고 다른 모델을 고르게 한다.

**ModelScope (무료 체험)**
1. modelscope.cn 가입 → 알리바바 클라우드 계정 인증(커뮤니티 자료 기준) → 계정 설정의 "액세스 토큰"에서 토큰 생성.
2. 앱: 설정 → "ModelScope · 무료 체험" → 토큰 입력 → 연결 테스트(`GET /v1/models` 로 토큰만 확인).
- 흐름: ① `POST /v1/images/generations`(JSON `{model, prompt, size}` + 헤더 `X-ModelScope-Async-Mode: true`) → `task_id` ② `GET /v1/tasks/{task_id}`(헤더 `X-ModelScope-Task-Type: image_generation`)를 3초, 이후 4초 간격으로 반복 → `task_status` 가 `SUCCEED` 면 `output_images[0]` ③ 그 주소(알리바바 클라우드 OSS)를 앱이 직접 내려받는다. `FAILED` 면 사유를 보여 준다.
- 중간에 "취소"하면 다음 상태 확인부터 보내지 않는다(이미 만들어진 작업은 서버에서 계속될 수 있다).

## 문구만으로 그리기
- **홈 "AI로 이미지 만들기"**: 제공자 선택 → 문구(예시 칩) → (정사각/가로/세로 — Cloudflare 는 1024² 고정) → 만들기 → "편집하기"로 편집기에서 바로 열기. **Cloudflare 만** 한국어를 **영어로 번역**해서 보낸다(`m2m100`, 실패하면 원문; 스위치로 끌 수 있고, 실제로 보낸 문구를 결과 아래에 보여 준다). Pollinations·ModelScope 는 문구를 그대로 보낸다(문구를 다른 서버로 더 보내지 않기 위해).
- **영역 "문구로 채우기"**: 선택 영역 **안쪽을 새로 그린 그림으로 채운다**(하늘·잔디·물결·벽돌 같은 "내용"을 설명). Cloudflare 는 AI 요청 탭의 "사진 보고 편집 / 문구로 채우기" 스위치로 고르고, Pollinations·ModelScope 는 항상 이 방식이다. 사진은 전송하지 않고, 그린 이미지를 선택 영역에 덮도록 잘라 맞춘 뒤 선택 안쪽에만 합성하며, 생성물이라 색 보정(톤 맞춤)은 끈다. 선택 안의 사물을 *고치는* 용도는 아니다.
- **동의**: 사진 없이 문구만 보내는 경우는 제공자별로 별도 동의("AI 서버로 문구를 보내요")를 받는다.

## 마스크가 없는 모델(Cloudflare 편집)에게 위치를 알리는 법
FLUX.2 는 마스크 입력이 없다. 그래서 **원본 크롭(이미지 1)** 과 **편집할 곳을 마젠타로 칠하고 테두리를 그린 같은 크롭(이미지 2)** 을 함께 보내고, "이미지 2의 표시된 곳만 바꾸고 나머지는 그대로, 표시 없이 이미지 1 전체를 돌려줘" 라고 지시한다. 모델이 표시 밖을 조금 바꿔도 **결과는 선택 안쪽에만 합성**하고, 선택 바로 바깥의 평균 색 차이로 밝기·색 drift 를 보정하므로 이음새가 줄어든다. 무료 모델은 결과가 들쭉날쭉할 수 있어 "다시 생성"을 쓰도록 했다.

## 데이터 흐름과 프라이버시
```
편집(Cloudflare):  [사진] → 선택(마스크) → 요청 크롭(선택+주변) + 표시 이미지 + 문구 → (JS) 업로드 청크 → (Java AiClient) HTTPS → Cloudflare → 결과 → (JS) 선택 안쪽만 합성
문구 생성(3종):    문구 → (JS) → (Java AiClient) HTTPS → 제공자 → (ModelScope: 작업 확인 반복 → 결과 주소 내려받기) → (JS) 선택 안쪽 합성 / 편집기로 열기
```
- **보내는 것**: 편집은 선택 영역과 그 주변을 잘라 낸 이미지 2장 + 문구, 생성은 **문구만**. **전체 사진은 보내지 않는다.** 편집 요청 중에는 "보낸 이미지(파란색 = 수정 영역)" 미리보기를 보여 준다.
- **첫 요청 전 동의**(제공자·종류별): 서버 호스트·전송 내용을 알린다. 무료/체험 서비스는 **제공사 정책에 따라 보낸 내용이 저장·개선·공개에 쓰일 수 있다**는 경고를 함께 보여 주므로 민감한 문구·사진은 피할 것. Pollinations 는 문구가 주소에 담긴다는 점, ModelScope 는 결과 이미지를 알리바바 클라우드 주소에서 받는다는 점도 알린다.
- **인터넷 권한(INTERNET)** 은 이 기능 때문에 있다. 웹 화면(WebView)은 여전히 CSP + 외부 요청 403 이라 인터넷에 직접 접근할 수 없고, 네이티브 `AiClient` 만 나간다. AI 기능을 한 번도 쓰지 않으면 앱은 인터넷을 쓰지 않는다.
- **AiClient 제한**: 제공자 프로필별로 서버(고정 https 주소 — 더 이상 사용자가 바꿀 수 없다)와 **경로·메서드·본문 형식·헤더 허용 목록**만 통과한다.
  - Cloudflare: `POST /accounts/{account}/ai/run/@cf/<벤더>/<모델>`(JSON 또는 multipart) · `GET /accounts/{account}/ai/models/search`. `{account}` 는 네이티브가 저장값으로 치환.
  - Pollinations: `GET /prompt/<A-Za-z0-9%._~->{1,2400}` + 쿼리 `width/height/seed` 류(`[A-Za-z0-9=&._,%:-]`, 160자). **인증 헤더를 붙이지 않는다.**
  - ModelScope: `POST /images/generations`(JSON, 헤더 `X-ModelScope-Async-Mode` 는 네이티브가 고정값으로 붙임) · `GET /tasks/{id}`(id 패턴 제한, 헤더 `X-ModelScope-Task-Type`) · `GET /models`.
  - **결과 이미지 내려받기(ModelScope 만)**: JS 가 알려 준 주소를 그대로 믿지 않고 네이티브가 검사한다 — `https` 만, 사용자 정보·포트·`#조각` 금지, 호스트가 `*.aliyuncs.com` / `*.modelscope.cn` / `*.modelscope.ai` 일 때만(`aliyuncs.com.evil.com`·`xaliyuncs.com` 거부), 경로·쿼리 문자 제한(길이 상한), **`Authorization` 을 붙이지 않고** 리다이렉트도 따라가지 않는다.
  - 공통: `.`/`..` 구간·IP·localhost·사내 도메인 거부, 리다이렉트 미추적, 요청 24MB / 응답 48MB 상한, `Authorization` 은 네이티브에서만 붙임. 모든 응답은 **원본 그대로(raw)** JS 로 돌려주고, JS 는 이미지를 **바이트(PNG/JPEG/WebP 머리글)로 확인**한 뒤에만 쓴다(Content-Type 을 믿지 않음; 이미지가 아니면 앞부분 텍스트를 사유로 안내).
- **키 보관**: AES-256-GCM 으로 암호화해 앱 전용 저장소(SharedPreferences)에 두고, 웹에는 `cf-…abcd` 힌트와 계정 ID(비밀 아님)만 돌려준다. 제공자별(`cloudflare` · `modelscope`; Pollinations 는 키 없음)로 저장·삭제된다. 암호화 키는 세 단계로 시도한다: ① Android Keystore 별칭 v1 → ② Keystore 별칭 v2 → ③ 앱 전용 폴더의 임의 AES-256 키 파일(Keystore 를 못 쓰는 에뮬레이터 등; 보호가 조금 약하므로 설정 화면에 표시). 평문 저장은 하지 않는다. 저장 직후 같은 방식으로 다시 풀어 보아 일치할 때만 "저장했어요"라고 하고, 이미 저장된 키나 Keystore 별칭은 지우지 않는다. 저장된 키를 풀 수 없게 되면 "읽을 수 없음"으로 표시한다("키 없음"과 구분).
- **삭제된 제공자의 데이터 정리**: 앱 시작 시 `KeyVault` 가 예전 OpenAI(접두사 없는 항목)·`openrouter.*`·`openai.*` 저장 항목을 모두 지운다. 웹 설정은 `aiConfig()` 가 `p.openai/openrouter`, 동의, `quality/n/model/consent` 같은 옛 항목을 지우고 제공자가 Cloudflare 로 돌아간다(`genProvider` 가 옛 값이면 삭제).

## 동작 상세
- **선택**: 올가미(손 떼면 닫힘)·브러시·사각형·원형, 추가/빼기, 선택 되돌리기, 반전, 해제, 영역 넓히기/좁히기(±30), 경계 부드럽게. 확대/이동(핀치)하며 정밀하게 그릴 수 있다.
- **요청 크롭**: 선택 영역 + 주변(좁게 15% / 보통 40% / 넓게 90%)을 제공자의 크기 클래스에 비율을 맞춰 **실제 주변 이미지로 넓혀서** 채운다(Cloudflare 입력 480 이하(문서상 512 미만) → 출력 2배). 문구만 보내는 제공자는 영역의 위치·크기만 계산한다. 영역은 보정·레이어까지 합성된 "보이는 그대로"를 작업 해상도로 다시 렌더해서 쓴다.
- **결과 합성**: 결과를 **선택(+부드러운 경계) 안쪽에만** 쓴다. 출력 해상도가 요청보다 큰 제공자는 패치를 출력 해상도로 만든다.
- **한계**: 생성 해상도가 1K 안팎(Pollinations 는 768 안팎)이라 큰 영역은 덜 선명할 수 있다(작은 영역이 가장 좋음). 얼굴·글자·손의 정확도는 모델에 달렸다. 이후 보정(노출 등)을 바꿔도 AI 레이어는 그 시점의 결과다.

## 비용·한도(참고)
- Cloudflare: 무료 계정 하루 10,000 Neurons. 모델 크기·출력 크기에 따라 하루 몇 장~수십 장 수준.
- Pollinations: 무료. 한 번에 한 장, 약 45초 간격(IP 기준). 이 앱은 요청 사이 간격을 강제하지 않고 서버의 429/402 를 쉬운 말로 알린다.
- ModelScope: 무료 체험 한도(하루 호출 수는 모델·시기에 따라 바뀌며 이 환경에서는 공식 값을 확인하지 못했다).

## 미검증 항목(중요)
- 이 개발 환경에서는 Cloudflare·Pollinations·ModelScope **공식 문서/API 에 접속할 수 없어 실제로 호출해 보지 못했다.** 요청·응답 형식은 공개된 예제 코드·README·검색 결과를 기준으로 구현했고, 모의 서버(JVM)와 가짜 브리지(E2E)로만 검증했다. `enter.pollinations.ai`(키 기반 새 API 문서)·`lilting.ch`·`skills.sh` 는 열 수 없었다.
- 특히 확인이 필요한 곳:
  - ⓪ Cloudflare: FLUX.2 가 **무료 계정**에서 실제로 호출되는지, `m2m100` 한국어 코드(`ko`→`en`), FLUX.1 schnell 응답 형식(JSON/바이너리 둘 다 처리), `multipart`(`input_image_0/1`, `width`, `height`) 입력과 `result.image`(base64) 출력.
  - ① Pollinations: 키 없는 클래식 주소(`image.pollinations.ai/prompt`)가 **지금도** 열려 있는지, 한도(약 45초/장)·면적 상한(768²)이 그대로인지. 키가 필요한 새 API(`gen.pollinations.ai`)가 있다는 정보는 있으나 확인하지 못해 쓰지 않았다 — 클래식 주소가 막히면 앱이 서버의 사유를 보여 준다.
  - ② ModelScope: 헤더 값(`X-ModelScope-Async-Mode`, `X-ModelScope-Task-Type`)·필드 이름(`task_id`, `task_status`, `output_images`)·결과 주소 도메인(`*.aliyuncs.com` 등)·무료 한도·계정 인증 요건은 **커뮤니티 예제**(아래 출처) 기준이다. 결과 주소가 다른 도메인이면 앱이 "허용되지 않은 주소"로 거부하므로, 그 경우 알려 주면 허용 목록을 맞춘다.
- 어긋나면 앱이 서버의 오류 사유를 그대로 보여 주므로 그 문구를 알려 주면 맞춰 고칠 수 있다.

## 키 입력이 안 될 때 (1.3.1)
- **제보**: "API 입력하면 오류남, 키가 사라짐".
- **원인 1(재현·수정)**: 설정(모달) 위에서는 오류 안내(토스트)가 시트 *뒤*에 가려져 보이지 않았다(토스트 z-index 40 < 모달 100). 아무 말 없이 실패하는 것처럼 보이고, 창을 닫으면 입력한 키도 함께 사라졌다. → 토스트를 모달 위(화면 위쪽)로 올리고, 키 입력 바로 아래에 **계속 보이는 안내**(`role=alert`)를 두었다. 오류가 나도 입력한 키는 그대로 둔다.
- **원인 후보 2(재현 불가, 방어)**: 이 기기의 Keystore 가 키 생성/암호화에 실패하는 경우(일부 기기·에뮬레이터). → 위의 세 단계 대체 저장 + 저장 직후 확인 + 실패 원인(예외 이름) 표시. 키 값은 오류 문구에 넣지 않는다.
- **입력 정리**: `Bearer xxx`/`Authorization: Bearer xxx` 통째로, 따옴표·쉼표·공백·보이지 않는 문자는 걷어 낸다. Cloudflare 계정 ID 는 대시보드 주소나 "Account ID: …" 처럼 글자가 섞여 있어도 32자리를 찾는다. 계정 ID 칸과 토큰 칸이 바뀐 경우를 알려 준다.
- **"문제 해결 → 보관 기능 점검"**: 기기 보안 저장소/보조 키/앱 전용 저장소가 각각 암호화→복호화를 해내는지 보여 준다(`hw=ok sw=ok` 형태, 키 값은 쓰지 않는다). 키가 필요한 제공자(Cloudflare·ModelScope)의 설정에만 나온다.
