# AI 수정 (영역 선택 → AI 편집) · AI로 이미지 만들기 — 설계·사용·프라이버시 (v1.3.0)

## 한눈에
- **하는 일**: 사진에서 올가미/브러시/사각형/원형으로 영역을 고르고 "셔츠를 파란색으로", "이 물체 지워 줘" 처럼 말하면, **그 영역(+주변)만** AI 에 보내 고친 결과를 **선택 안쪽에만** 합성한다.
- **결과는 비파괴 레이어**: 잠긴 이미지 레이어(레이어 목록에 "AI 수정 · 문구")라서 숨기기·삭제·실행 취소·자동 복구가 된다. 적용 강도 슬라이더, 변형 고르기(OpenAI 1~3장), 다시 생성 지원.
- **제공자 3종(설정에서 선택)**: OpenAI(유료) · **OpenRouter(무료 모델)** · **Cloudflare Workers AI(하루 무료)**. 키는 제공자마다 따로 저장한다.
- **문구만으로 그리기(v1.3.0)**: 홈의 **"AI로 이미지 만들기"** 와 영역 편집의 **"문구로 채우기"** — Cloudflare FLUX.1 schnell(무료)·OpenAI. 사진은 보내지 않는다. 무료 모델 조사 결과는 [`FREE_IMAGE_MODELS_2026-11-15.md`](FREE_IMAGE_MODELS_2026-11-15.md).

## 제공자
| | OpenAI | OpenRouter | Cloudflare Workers AI |
|---|---|---|---|
| 비용 | 유료(API 결제) | **`:free` 모델 무료**(일일 한도) | **하루 무료 한도**(무료 계정, 카드 불필요) |
| 편집 방식 | **진짜 마스크**(투명 = 편집 영역) | 이미지를 내는 LLM — **표시 이미지**로 위치 전달 | FLUX.2 편집 — **표시 이미지**로 위치 전달 |
| 엔드포인트 | `POST /v1/images/edits` | `POST /api/v1/chat/completions` (`modalities`) | `POST /client/v4/accounts/{id}/ai/run/@cf/…` (multipart) |
| 필요한 것 | API 키 | API 키(`sk-or-…`) | **계정 ID + API 토큰** |
| 모델 | **자동**: 키로 조회해 최신 `gpt-image-*` | **자동**: 지금 목록에서 "무료 + 이미지 입력" 중 가장 새로운 것(없으면 안내) | 기본 `flux-2-klein-4b`(가볍고 빠름), `flux-2-klein-9b`·`flux-2-dev` 선택 가능 |
| 변형 | 1~3장 | 1장(다시 생성으로 재시도) | 1장 |

- **Gemini API 는 왜 없나**: Gemini API 의 이미지 모델은 무료 티어가 없다는 보고가 일치한다(Google AI 포럼 답변, 무료 키로 호출 시 429 `limit: 0`). 공식 가격 페이지는 이 환경에서 열 수 없어 직접 확인하지는 못했다. 유료로 쓸 거면 OpenRouter 로 Gemini 이미지 모델을 고를 수 있다.
- **텍스트 LLM 만으로는 안 된다**: 이미지를 **출력**하는 모델이어야 한다(위 3종은 모두 해당).
- **ChatGPT 구독 ≠ API**: 구독으로 로그인하는 방식은 없다. OpenAI 는 별도 API 결제가 필요하다.

## 무료로 시작하기
**Cloudflare (꾸준히 무료)**
1. dash.cloudflare.com 에 무료 가입(카드 불필요).
2. **계정 ID**: 대시보드 주소의 32자리 값.
3. **API 토큰**: My Profile → API Tokens → Create Token → "Workers AI" 템플릿.
4. 앱: AI 수정 → AI 요청 → "Cloudflare · 하루 무료" → 계정 ID·토큰 입력 → 연결 테스트.
- 무료 한도는 하루 10,000 Neurons(UTC 자정 초기화). 초과하면(Cloudflare 오류 3036) "오늘의 무료 사용량을 모두 썼어요" 로 안내한다.
- **주의**: Cloudflare 는 2026-07 부터 일부 모델을 무료 플랜에서 막았다(403, 내부 오류 5035 — 공지된 모델은 Kimi·GLM 등 **텍스트** 모델). FLUX.2 가 무료 계정에서 되는지는 확인하지 못했다. 막히면 앱이 "유료 플랜 필요" 로 안내하고 다른 모델(예: `flux-2-klein-4b`)을 고르게 한다.

**OpenRouter (무료 모델)**
1. openrouter.ai 가입 → Keys 에서 키 발급.
2. 앱: "OpenRouter · 무료 모델" → 키 입력 → 연결 테스트(지금 쓸 수 있는 무료 이미지 편집 모델 목록 표시).
- 무료 모델은 **수시로 바뀌고 모델마다 하루 요청 수 제한**이 있다. 앱이 요청 때마다(저장된 선택이 없으면) 목록을 조회해 고르고, 없으면 "무료 이미지 편집 모델이 없어요" 라고 알린다.

## 문구만으로 그리기 (생성 전용 모델)
- **모델**: Cloudflare `@cf/black-forest-labs/flux-1-schnell`(유튜브 단골 무료 모델). 요청은 `{prompt}` 하나뿐이고, 응답은 JSON(`result.image` base64) 또는 이미지 바이너리를 모두 받는다.
- **홈 "AI로 이미지 만들기"**: 문구 입력(예시 칩) → 한국어면 **영어로 번역**(Cloudflare `m2m100`, 실패하면 원문) → 생성 → "편집하기"로 편집기에서 바로 열기. 번역 스위치로 끌 수 있고, 실제로 보낸 문구를 결과 아래에 보여 준다. OpenAI 로도 만들 수 있다(`POST /images/generations`, 비율 1:1·3:2·2:3).
- **영역 "문구로 채우기"**: Cloudflare 를 쓰면 AI 요청 탭에 "사진 보고 편집 / 문구로 채우기" 스위치가 생긴다. 후자는 선택 영역 **안쪽을 새로 그린 그림으로 채운다**(하늘·잔디·물결·벽돌 같은 "내용"을 설명). 사진은 전송하지 않고(문구만), 그린 이미지를 선택 영역에 덮도록 잘라 맞춘 뒤 선택 안쪽에만 합성하며, 생성물이라 색 보정(톤 맞춤)은 끈다. 선택 안의 사물을 *고치는* 용도는 아니다.
- **동의**: 사진 없이 문구만 보내는 경우는 별도 동의("AI 서버로 문구를 보내요")를 받는다.

## 마스크가 없는 모델에게 위치를 알리는 법
OpenRouter·Cloudflare 모델은 마스크 입력이 없다. 그래서 **원본 크롭(이미지 1)** 과 **편집할 곳을 마젠타로 칠하고 테두리를 그린 같은 크롭(이미지 2)** 을 함께 보내고, "이미지 2의 표시된 곳만 바꾸고 나머지는 그대로, 표시 없이 이미지 1 전체를 돌려줘" 라고 지시한다. 모델이 표시 밖을 조금 바꿔도 **결과는 선택 안쪽에만 합성**하고, 선택 바로 바깥의 평균 색 차이로 밝기·색 drift 를 보정하므로 이음새가 줄어든다. 무료 모델은 결과가 들쭉날쭉할 수 있어 "다시 생성"을 쓰도록 했다.

## 데이터 흐름과 프라이버시
```
[사진] → 선택(마스크) → 요청 크롭(선택+주변) → (OpenAI: image+mask / 그 외: image+표시 이미지) + 문구
        → (JS) 업로드 청크 → (Java AiClient) HTTPS → 제공자 서버 → 결과
        → (JS) 선택 안쪽만 합성 → 이미지 레이어
```
- **보내는 것**: 선택 영역과 그 주변을 잘라 낸 이미지 1~2장, 입력한 문구, 모델/크기. **전체 사진은 보내지 않는다.** 요청 중에는 "보낸 이미지(파란색 = 수정 영역)" 미리보기를 보여 준다.
- **첫 요청 전 동의**(제공자별): 서버 호스트·전송 내용을 알린다. 무료/체험 서비스는 **제공사 정책에 따라 보낸 내용이 저장·개선에 쓰일 수 있다**는 경고를 함께 보여 주므로 민감한 사진은 피할 것.
- **인터넷 권한(INTERNET)** 은 이 기능 때문에 있다. 웹 화면(WebView)은 여전히 CSP + 외부 요청 403 이라 인터넷에 직접 접근할 수 없고, 네이티브 `AiClient` 만 나간다.
- **AiClient 제한**: 제공자 프로필별로 서버(고정 https 주소; OpenAI 만 사용자가 공개 도메인으로 변경 가능)와 **경로·본문 형식 허용 목록**만 통과한다(예: OpenRouter 는 `/chat/completions`·`/models`·`/key`, Cloudflare 는 `/accounts/{account}/ai/run/@cf/<벤더>/<모델>`·`/accounts/{account}/ai/models/search`). `.`/`..` 구간·IP·localhost·사내 도메인·쿼리 외 문자 거부, 리다이렉트 미추적, 요청 24MB/응답 96MB 상한, `Authorization` 은 네이티브에서만 붙임. Cloudflare 계정 ID 는 `{account}` 자리표시자를 네이티브가 저장값으로 치환한다.
- **키 보관**: AES-256-GCM 으로 암호화해 앱 전용 저장소(SharedPreferences)에 두고, 웹에는 `sk-…abcd` 힌트와 계정 ID(비밀 아님)만 돌려준다. 제공자별로 저장·삭제된다. 암호화 키는 세 단계로 시도한다(1.3.1~): ① Android Keystore 별칭 v1(기본, 키가 기기 보안 영역에 있음) → ② Keystore 별칭 v2(v1 이 망가진 기기용) → ③ 앱 전용 폴더의 임의 AES-256 키 파일(Keystore 를 아예 못 쓰는 에뮬레이터·PC 용 안드로이드 등). ③은 앱 샌드박스가 지켜 주는 수준이라 보호가 조금 약하므로 설정 화면에 그 사실을 표시한다. 평문 저장은 하지 않는다. **저장 직후 같은 방식으로 다시 풀어 보아 일치할 때만 "저장했어요"**라고 하고, 실패하면 다음 단계로 넘어가며, 이미 저장된 키나 Keystore 별칭을 지우지 않는다. 저장된 키를 풀 수 없게 되면(보안 저장소 초기화 등) "읽을 수 없음"으로 표시하고 키를 다시 입력하도록 안내한다("키 없음"과 구분).
- AI 수정을 한 번도 쓰지 않으면 앱은 인터넷을 쓰지 않는다.

## 동작 상세
- **선택**: 올가미(손 떼면 닫힘)·브러시·사각형·원형, 추가/빼기, 선택 되돌리기, 반전, 해제, 영역 넓히기/좁히기(±30), 경계 부드럽게. 확대/이동(핀치)하며 정밀하게 그릴 수 있다.
- **요청 크롭**: 선택 영역 + 주변(좁게 15% / 보통 40% / 넓게 90%)을 제공자의 크기 클래스에 비율을 맞춰 **실제 주변 이미지로 넓혀서** 채운다(OpenAI 1024²·1536×1024·1024×1536, OpenRouter 1024 안팎, Cloudflare 입력 480 이하(문서상 512 미만) → 출력 2배). 영역은 보정·레이어까지 합성된 "보이는 그대로"를 작업 해상도로 다시 렌더해서 쓴다.
- **결과 합성**: 결과를 **선택(+부드러운 경계) 안쪽에만** 쓴다. 출력 해상도가 요청보다 큰 제공자(Cloudflare)는 패치를 출력 해상도로 만든다.
- **한계**: 생성 해상도가 1~1.5K 안팎이라 큰 영역은 덜 선명할 수 있다(작은 영역이 가장 좋음). 얼굴·글자·손의 정확도는 모델에 달렸다. 이후 보정(노출 등)을 바꿔도 AI 레이어는 그 시점의 결과다.

## 미검증 항목(중요)
- 이 개발 환경에서는 OpenAI·Google·Cloudflare·OpenRouter 공식 문서/API 에 접속할 수 없어 **실제 키로 호출해 보지 못했다.** 요청·응답 형식은 공개된 사용 예와 검색 결과를 기준으로 구현했고, 모의 서버/가짜 브리지로만 검증했다.
- 특히 확인이 필요한 곳: ⓪ FLUX.2 모델이 **무료 계정**에서 실제로 호출되는지(FLUX.1 schnell 은 유튜브 영상 다수가 쓰는 경로), ⓪' `m2m100` 한국어 코드(`ko`→`en`) 와 FLUX.1 schnell 응답 형식(JSON/바이너리 둘 다 처리), ① Cloudflare REST 가 `multipart/form-data`(`input_image_0/1`, `width`, `height`) 입력과 `result.image`(base64) 출력을 쓰는지, ② 무료 모델이 우리의 2장 입력·`modalities` 요청을 받아들이는지, ③ OpenRouter 무료 이미지 모델이 지금 실제로 있는지. 어긋나면 앱이 서버의 오류 사유를 그대로 보여 주므로 그 문구를 알려 주면 맞춰 고칠 수 있다.

## 키 입력이 안 될 때 (1.3.1)
- **제보**: "API 입력하면 오류남, 키가 사라짐".
- **원인 1(재현·수정)**: 설정(모달) 위에서는 오류 안내(토스트)가 시트 *뒤*에 가려져 보이지 않았다(토스트 z-index 40 < 모달 100). 아무 말 없이 실패하는 것처럼 보이고, 창을 닫으면 입력한 키도 함께 사라졌다. → 토스트를 모달 위(화면 위쪽)로 올리고, 키 입력 바로 아래에 **계속 보이는 안내**(`role=alert`)를 두었다. 오류가 나도 입력한 키는 그대로 둔다.
- **원인 후보 2(재현 불가, 방어)**: 이 기기의 Keystore 가 키 생성/암호화에 실패하는 경우(일부 기기·에뮬레이터). → 위의 세 단계 대체 저장 + 저장 직후 확인 + 실패 원인(예외 이름) 표시. 키 값은 오류 문구에 넣지 않는다.
- **입력 정리**: `Bearer xxx`/`Authorization: Bearer xxx` 통째로, 따옴표·쉼표·공백·보이지 않는 문자는 걷어 낸다. Cloudflare 계정 ID 는 대시보드 주소나 "Account ID: …" 처럼 글자가 섞여 있어도 32자리를 찾는다. 계정 ID 칸과 토큰 칸이 바뀐 경우를 알려 준다.
- **"문제 해결 → 보관 기능 점검"**: 기기 보안 저장소/보조 키/앱 전용 저장소가 각각 암호화→복호화를 해내는지 보여 준다(`hw=ok sw=ok` 형태, 키 값은 쓰지 않는다). 계속 실패하면 이 결과 한 줄이면 원인을 알 수 있다.
