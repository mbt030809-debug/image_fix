- **제공자 4종(설정에서 선택, 키는 제공자마다 따로 저장, 모두 키/토큰 필요)**

  - **Google Gemini** — 내 API 키. 편집(원본 + 표시 사진) · 문구로 그리기(기본 `gemini-2.5-flash-image`, 일명 "나노 바나나").
  - **fal.ai · FLUX.1 Fill [dev]** — fal API 키. **진짜 마스크** 인페인팅(선택 안쪽만 새로 그림).
- **변경 이력**: 1.5.0 에서 OpenAI·OpenRouter 삭제(Cloudflare 유지, Pollinations·ModelScope 생성 추가) → **1.6.0 에서 Pollinations 삭제, ModelScope 는 생성 대신 Qwen-Image-Edit 편집으로 교체, Gemini · Hugging Face 추가.** 삭제된 제공자의 저장 키·설정·동의는 앱이 지운다. 이전 버전은 git 이력(`2038374` v1.4.0, 1.5.0)·이전 APK 로 되돌린다.

- **Gemini**: 요청 `{contents:[{parts:[문구, 원본, 표시본]}], generationConfig:{responseModalities:["TEXT","IMAGE"]}}`, 응답 `candidates[].content.parts[].inlineData.data`(base64). 글만 오거나 안전 정책으로 막히면(`promptFeedback.blockReason`/`finishReason`) 사유를 보여 준다. 문구 생성은 가로/세로/정사각 비율(`imageConfig.aspectRatio`)을 보낸다. 모델 목록 조회(`GET /models`)로 키를 확인한다. 무료 키로 이미지 모델을 부르면 429 `limit: 0` 이 올 수 있어 그때는 "무료 한도 0 → 결제 설정" 으로 안내한다.
- **ModelScope**: `X-ModelScope-Async-Mode: true` 로 작업을 만들고(편집은 작업 종류 `X-ModelScope-Task-Type: image-to-image-generation` — 네이티브가 spec 의 `tt` 로만 허용된 두 값 중 고름), 3초·4초 간격으로 `GET /v1/tasks/{id}` 확인 → `output_images[0]`(알리바바 클라우드 주소)을 네이티브가 내려받는다(허용 도메인·https·토큰 미전송).
- **fal.ai**: 마스크는 **흰색 = 채울 곳, 검정 = 유지**(선택 가장자리를 조금 넓힘). 결과는 data URI 이거나 fal 주소(`*.fal.media`/`*.fal.run` 만 내려받음). **1.6.x 의 Hugging Face 연동은 "모델을 찾을 수 없어요"(404)로 실제 동작하지 않아(HF 라우터에 FLUX.1 Fill 경로 없음) 1.7.1 에서 fal.ai 직접 연동으로 교체했다.** 저장돼 있던 Hugging Face 토큰은 앱이 지운다.

## 백그라운드에서도 계속 (1.7.0)
- AI 요청은 수십 초~수 분이 걸려서, 앱을 나가면(홈 버튼·다른 앱) 예전에는 중단되거나 결과를 못 받을 수 있었다. 이제 **요청이 진행되는 동안 포그라운드 서비스(`AiService`, 유형 dataSync)** 가 진행 중 알림("AI 작업 중")을 띄우고 프로세스·CPU(PARTIAL_WAKE_LOCK, 최대 12분)를 살려 둔다. 그 동안 WebView 를 멈추지 않아(`onPause` 에서 `web.onPause()` 생략) 상태 확인·결과 합성(JS)이 계속된다.
- **끝나면 알림**: 앱이 화면에 없을 때 "AI 수정 결과가 준비됐어요(또는 실패했어요) — 눌러서 확인" 알림을 띄우고, 누르면 앱으로 돌아와 결과를 확인·적용한다. 앱이 화면에 있으면 알림은 뜨지 않는다. 취소하면 알림 없이 서비스만 끈다.
- **권한**: `FOREGROUND_SERVICE` · `FOREGROUND_SERVICE_DATA_SYNC` · `WAKE_LOCK` · `POST_NOTIFICATIONS`(Android 13+ 는 첫 요청 때 한 번 물어봄 — 거부해도 작업은 이어지고 알림만 안 보인다). 서비스는 통신을 하지 않고 살려 두기만 하며, 12분이 지나거나 앱이 종료되면 스스로 꺼진다.
- **한계**: 편집기 화면을 닫거나 홈 화면으로 나가면 진행 중 요청은 취소된다(앱을 *나가는* 것과 다르다). 제조사별 배터리 절약 기능이 앱을 강제로 끄면 이어지지 않을 수 있다. 실기기에서 확인하지 못했다(에뮬레이션 없음) — 컴파일·정렬·서명과 가짜 브리지 E2E(`keepAlive` 켜짐/꺼짐, 완료·실패·취소 때 알림 여부)만 검증했다.

## 마스크가 없는 모델에게 위치를 알리는 법 (Cloudflare · Gemini · ModelScope)
**원본 크롭(이미지 1)** 과 **편집할 곳을 마젠타로 칠하고 테두리를 그린 같은 크롭(이미지 2)** 을 함께 보내고 "이미지 2의 표시된 곳만 바꾸고 나머지는 그대로, 표시 없이 이미지 1 전체를 돌려줘" 라고 지시한다(ModelScope 는 표시된 사진 1장만). 모델이 표시 밖을 조금 바꿔도 **결과는 선택 안쪽에만 합성**하고, 선택 바로 바깥의 평균 색 차이로 밝기·색 drift 를 보정한다. 무료 모델은 결과가 들쭉날쭉할 수 있어 "다시 생성"을 쓰도록 했다.

## 문구만으로 그리기
- **홈 "AI로 이미지 만들기"**: 제공자(Cloudflare·Gemini) → 문구(예시 칩) → (Gemini: 정사각/가로/세로) → 만들기 → "편집하기". **Cloudflare 만** 한국어를 영어로 번역해서 보낸다(`m2m100`, 실패하면 원문; 스위치로 끌 수 있음).
- **영역 "문구로 채우기"**: Cloudflare(모델 선택으로)·Gemini(방식 스위치)에서 선택 안쪽을 새로 그린 그림으로 채운다. 사진은 전송하지 않고, 그린 이미지를 선택 영역에 덮도록 잘라 맞춘 뒤 선택 안쪽에만 합성하며 색 보정은 끈다.
- **동의**: 사진을 보내는 경우와 문구만 보내는 경우를 제공자별로 따로 동의받는다.

## 데이터 흐름과 프라이버시
- **보내는 것**: 편집은 선택 영역과 주변을 잘라 낸 이미지(1~2장, fal.ai 는 이미지+마스크)와 문구, 생성은 **문구만**. **전체 사진은 보내지 않는다.** 편집 요청 중에는 "보낸 이미지" 미리보기를 보여 준다.
- **서버**: Cloudflare, ModelScope(+결과는 알리바바 클라우드 주소), Google(Gemini — 무료 사용 시 내용이 제품 개선에 쓰일 수 있음), fal.ai. 첫 요청 전 호스트와 전송 내용을 알리고 동의를 받는다.
- **인터넷 권한(INTERNET)** 은 AI 기능 때문에만 있다. WebView 는 CSP + 외부 요청 403 이라 인터넷에 직접 접근할 수 없고 네이티브 `AiClient` 만 나간다. AI 기능을 쓰지 않으면 앱은 인터넷을 쓰지 않는다.
- **AiClient 허용 목록**(경로·메서드·본문 형식·헤더, 고정 https 서버 — 사용자가 바꿀 수 없음): Cloudflare `POST /accounts/{account}/ai/run/@cf/<벤더>/<모델>`·`GET …/models/search` · ModelScope `POST /images/generations`·`GET /tasks/{id}`·`GET /models` · Gemini `POST /models/<gemini-…>:generateContent`·`GET /models` · fal.ai `POST /fal-ai/flux-lora-fill`(fal.run). 결과 주소 내려받기는 ModelScope(`*.aliyuncs.com`·`*.modelscope.cn`·`*.modelscope.ai`)와 fal.ai(`*.fal.media`·`*.fal.run`)만, https·포트/사용자 정보/조각 없음·경로/쿼리 문자 제한·인증 헤더 없음·리다이렉트 미추적. `.`/`..` 구간·IP·localhost 거부, 요청 24MB / 응답 48MB 상한, 키는 네이티브에서만 헤더에 붙임. 모든 응답은 raw 로 돌려주고 JS 는 이미지를 **바이트(PNG/JPEG/WebP 머리글)** 로 확인한 뒤에만 쓴다.
- **키 보관**: AES-256-GCM 암호화 후 앱 전용 저장소에 두고 웹에는 `AIz…3456` 힌트와 계정 ID(비밀 아님)만 돌려준다. 암호화 키는 ① Android Keystore 별칭 v1 → ② 별칭 v2 → ③ 앱 전용 키 파일 순으로 시도하고, 저장 직후 풀어 보아 일치할 때만 "저장했어요"라고 한다. 저장된 키를 풀 수 없으면 "읽을 수 없음".
- **삭제된 제공자 정리**: 시작 시 `KeyVault` 가 OpenAI·OpenRouter 항목을 지우고, 웹 설정은 `aiConfig()` 가 `openai/openrouter/pollinations` 설정·동의와 `quality/n/…` 옛 항목을 지운 뒤 제공자를 Cloudflare 로 되돌린다.

## 미검증 항목(중요)
- 이 개발 환경에서는 **어떤 제공자의 공식 문서·실제 API 에도 접속할 수 없어(huggingface.co·ai.google.dev 등 차단 포함) 실제로 호출해 보지 못했다.** 요청·응답 형식은 아는 REST 규약·공개 예제·검색 결과 기준이고, JVM 모의 서버와 가짜 브리지로만 검증했다. 어긋나면 앱이 서버의 오류 문구를 그대로 보여 주니 그 문구를 알려 주면 맞춘다.
- 특히: ⓐ **Gemini** — 이미지 모델의 무료 한도(0 일 수 있음), `responseModalities`/`imageConfig` 형식. ⓑ **ModelScope Qwen-Image-Edit** — 공개 예제는 공개 이미지 URL(`image_url`)을 우선 쓰고 안 되면 `image` 로 base64 데이터 주소를 보낸다; 둘 다 보내지만 서버가 데이터 주소를 받는지는 미확인. 작업 종류 헤더 값·응답 필드·무료 한도·계정 인증 요건도 커뮤니티 예제 기준. ⓒ **fal.ai** — `fal.run/fal-ai/flux-lora-fill` 의 동기 호출·`Authorization: Key`·`image_url`/`mask_url`(data URI)·`sync_mode` 는 fal 문서 기준이며 실서버 미검증(비용 발생 가능). ⓓ Cloudflare — FLUX.2 의 무료 계정 가능 여부, `m2m100` 한국어 코드.

## 키 입력이 안 될 때 (1.3.1)
- 설정(모달) 위에서 오류 토스트가 시트 뒤에 가려지던 문제를 고쳐, 입력 아래에 **계속 보이는 안내**(`role=alert`)를 둔다. 오류가 나도 입력한 키는 지우지 않는다. `Bearer xxx`/따옴표/보이지 않는 문자는 걷어 내고, Cloudflare 계정 ID 는 주소째 붙여 넣어도 32자리를 찾는다. "문제 해결 → 보관 기능 점검"으로 기기 암호화 저장소를 점검한다(`hw=ok sw=ok`).
