# ImageFix 계획 (2026-11-14)

## 목표
- 안드로이드 APK 이미지 편집 앱, 편집 앱이 지원하는 기능을 최대한 포함
- 한국어 우선 UI, 완전 오프라인(인터넷 권한 없음), 사진은 기기 밖으로 나가지 않음

## 구조
- `app/` : Android 쉘(Java, WebView). 갤러리 저장(MediaStore)/공유/카메라/외부 앱 연결/HEIC 변환
- `web/` : 편집기 본체(바닐라 JS). 워커에서 픽셀 파이프라인 실행, esbuild 번들 → `app/src/main/assets/www`
- `scripts/` : SDK 없이 APK 빌드(aapt → javac → d8 → zipalign → apksigner)
- `tests/` : 엔진 단위 테스트(Node) + Playwright E2E
- `.claude/skills/` + `docs/design_brief_2026-11-14.md` : 서브에이전트가 찾아 설치한 디자인 스킬과 UI 브리프

## 편집 모델
- 비파괴: 원본 → 리터치 → 지오메트리(자르기/회전/원근) → 현상(보정·필터·LUT) → 로컬 마스크 → 효과 → 레이어/프레임
- 문서 상태는 불변 스냅샷 → 무제한에 가까운 실행 취소/다시 실행
- 미리보기는 저해상도(드래그 중)/고해상도, 내보내기는 원본 해상도로 같은 파이프라인 재실행

## 기능 (구현됨)
- 자르기: 비율 프리셋, 핸들, 90° 회전, 좌우/상하 뒤집기, 수평 보정, 수직/수평 원근
- 조정: 노출·밝기·대비·하이라이트·그림자·화이트·블랙·안개 제거·페이드·채도·생동감·색온도·틴트·색상 회전·선명도·명료도·질감·노이즈 제거·비네팅·그레인, 자동 보정, 히스토그램
- 필터 36종(8개 분류) + 강도, 나의 프리셋 저장, .cube LUT 가져오기
- 색상: HSL 8색, 컬러 그레이딩(스플릿 토닝), 흑백 채널 믹서/세피아
- 곡선: RGB/R/G/B, 점 추가·이동·삭제, 숫자 입력, 프리셋
- 효과 33종: 블러(일반/모션/줌/틸트시프트/원형), 아트(모자이크/하프톤/유화/스케치/만화/엠보스/외곽선/포스터/솔라라이즈/흑백2색/반전/듀오톤), 빛(글로우/소프트포커스/빛샘/빛망울/눈), 왜곡(소용돌이/볼록오목/물결/어안/거울·만화경), 글리치·레트로(글리치/색수차/RGB 분리/VHS)
- 리터치: 치유, 복제, 지우기(인페인팅), 리퀴파이(밀기/확대/축소/비틀기/복원)
- 브러시(로컬 보정): 브러시/선형/원형/색 범위 마스크 + 노출·대비·채도·색온도·선명·흐림·스무딩 등, 프리셋(피부/치아/눈/적목/컬러 스플래시)
- 텍스트(글꼴 8종·색·그라데이션·외곽선·그림자·배경 상자·정렬·간격), 스티커(이모지/도형/내 사진·혼합 모드), 그리기(펜/마커/형광펜/네온/스프레이/점선/지우개), 프레임 12종, 배경 제거(자동/마술봉/브러시) + 배경 교체, 레이어 목록
- 크기: 가로×세로 px·배율, SNS/화면/인쇄·증명 프리셋, 채우기·여백·늘이기 (저장 결과가 지정 크기와 일치)
- 리터치에 픽셀 유동화(밀기·확대·축소·비틀기·복원), 콜라주, 작업 자동 복구, 번들 폰트(OFL)
- 저장: JPEG/PNG/WebP, 품질, 크기, 갤러리 저장/공유, 원본 보기(누르고 있기)
- **v1.1 추가 — AI 수정**: 올가미/브러시/사각형/원형 영역 선택 → 그 영역(+주변)만 AI 에 요청 → 선택 안쪽만 합성하는 비파괴 레이어. 내 API 키(Keystore 암호화), 첫 요청 전 동의, INTERNET 권한은 이 기능 전용.
- **v1.2 추가 — 무료 AI 제공자**: Cloudflare Workers AI(FLUX.2, 하루 무료)·OpenRouter(무료 :free 이미지 모델 자동 탐색) + 마스크 없는 모델용 "표시 이미지", 제공자별 키/모델/동의, 네이티브 제공자 프로필(허용 경로). 설계·프라이버시: `AI_EDIT_2026-11-14.md`
- **v1.5 변경 — AI 제공자 정리**: OpenAI·OpenRouter 삭제, **Cloudflare**(편집·생성·번역) 유지, **Pollinations.ai**(키 없이 문구 생성)·**ModelScope API-Inference**(무료 체험 토큰, 비동기 작업 + 결과 주소 내려받기) 추가. 네이티브 `AiClient` 는 제공자별 허용 목록 + 결과 주소(허용 도메인·https) 검증으로 일반화. 자세한 내용은 `docs/AI_EDIT_2026-11-14.md`.

## 한계
- 배경 제거는 ML이 아닌 색 기반(단색 배경에 적합)
- 지우기는 패치 합성이 아닌 주변색 확산 + 질감 노이즈(작은 물체용)
- 실기기 테스트 불가 환경에서 빌드: 쉘(Java)은 컴파일·서명·정렬 + AI 릴레이는 JVM 모의 서버로 검증, 웹 UI는 헤드리스 크롬으로 검증
- AI 수정은 실제 키로 호출해 보지 못함(제공자 공식 문서 접속 불가, 모의 서버/가짜 브리지로만 검증)
