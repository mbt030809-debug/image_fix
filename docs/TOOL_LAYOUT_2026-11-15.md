# 도구 구성(상위/하위 목록) · 패널 높이 조절 · 여권 사진 가이드 (v1.4.0)

## 상위/하위 목록
- 하단 도구 16개가 한 줄에 늘어서 길었던 것을 **상위 6개**로 줄이고, 상위를 누르면 **하위 목록(5개 이하, 스크롤 없이 한눈에)** 이 그 위에 펼쳐진다. 하위를 누르면 예전과 같은 도구 패널이 열린다.

| 상위 | 하위 | 비고 |
|---|---|---|
| 캔버스 | 자르기 · 크기 · 프레임 | 크기의 여백(흐린 배경/단색)이 프레임 기능으로 만들어져 같이 둠 |
| 보정 | 조정 · 색상 · 곡선 · 필터 · 효과 | |
| 다듬기 | 리터치 · 브러시 · 배경 제거 | 배경 제거는 AI 가 아니라 기기 안에서 색 기준으로 처리 |
| 꾸미기 | 텍스트 · 스티커 · 그리기 | |
| AI 도구 | 영역 수정 · 이미지 만들기 · AI 설정 | 영역 수정 = 예전 "AI 수정"(패널 제목은 "AI 영역 수정"). 이미지 만들기·AI 설정은 창을 여는 항목 |
| 레이어 | (바로 열림) | 하위 없음 |

- 같은 상위를 다시 누르면 접힌다(열린 도구도 닫힘). 다른 상위를 누르면 열린 도구를 닫고 그 상위의 하위 목록을 보여 준다.
- 코드에서 도구를 열어도(레이어의 "편집", 리터치의 인물 보정 등) 상위/하위 목록이 맞춰진다. 새 사진을 열거나 홈으로 가면 접힌다.
- 뒤로가기: 열린 도구 닫기 → 펼친 하위 목록 접기 → (그다음에) 편집기 나가기.
- "이미지 만들기"는 만든 이미지를 편집하면 지금 사진이 닫히므로, 저장하지 않은 변경이 있으면 먼저 묻는다.
- 가로/태블릿: 분류 레일(72px) 옆에 하위 레일이 붙고, 그 옆이 사진·옆 패널.
- 구현: `web/src/tools/index.js`(TOOLS · ACTIONS · GROUPS), `web/src/editor.js`(toggleGroup/setGroup), 검증 `web/tests/tools.unit.mjs`, `tests/e2e/groups.cjs`.

## 패널 높이 조절
- 패널 위쪽 **손잡이(—)를 누른 채 위아래로 끌면** 높이가 바뀐다(제목 줄을 잡아도 되고, 제목 줄의 버튼은 제외). 터치 영역은 손잡이 주변까지 넓혔고, 잡으면 손잡이가 강조색으로 바뀐다.
- 한계: 아래쪽 끝 = 손잡이 + 제목 줄만 남는 **접힘**, 위쪽 끝 = 사진 영역이 16%(최소 120px)가 되는 곳. 위/아래 막대는 항상 화면 안에 남는다.
- 높이에 따라 도구 내용이 바뀐다: 낮으면 간단(칩 + 슬라이더 1개), 충분히 크면 전체 목록(예: 조정의 모든 슬라이더·히스토그램). 경계에서 깜박이지 않도록 12px 이력 현상을 둔다.
- 도구마다 높이를 **편집기 높이 대비 비율**로 기억한다(설정에 저장 → 앱을 다시 켜도 유지, 회전·키보드로 화면이 바뀌어도 비율대로 다시 맞춤). 손잡이를 **누르면**(끌지 않고) 기존처럼 접기/펼치기이며 기억한 높이는 지운다.
- 키보드: 손잡이에 포커스 → ↑/↓ 로 24px 씩, Enter/Space 로 접기/펼치기.
- 가로/태블릿의 옆 패널은 높이가 고정이라 이 기능을 쓰지 않는다(손잡이 없음).
- 구현: `Editor.initSheetResize` 등(`web/src/editor.js`), 검증 `tests/e2e/sheet_resize.cjs`.

## 자르기 · 여권 사진 가이드
- 비율 프리셋 **"여권 3.5×4.5"**(7:9) 추가 — 자유·원본 바로 다음 칸. 다른 비율(1:1 ~ 21:9)은 그대로.
- 고르면 캔버스(자르기 사각형 안)에 **얼굴 크기 기준**이 겹쳐 보인다: **정수리 선**(위에서 3mm), **턱 끝 띠**(정수리에서 32~36mm 아래, 초록), 세로 중앙선, 그 사이를 잇는 **얼굴 틀(타원)**, 라벨("정수리", "턱 끝 · 얼굴 3.2~3.6cm"). 정수리를 위 선에, 턱 끝을 초록 띠 안에 맞추면 된다. 격자(3등분)는 겹쳐서 끈다. 사각형을 옮기거나 키워도 가이드가 같이 따라간다.
- **근거**: 여권 사진 가로 3.5×세로 4.5cm, 얼굴 길이(정수리~턱) **3.2~3.6cm = 사진 높이의 71~80%**, 흰 배경·정면 — ICAO 기준을 따르는 외교부 여권사진 규격(지자체 여권 안내문에 같은 수치로 게시). 주민등록증·운전면허 사진도 3.5×4.5cm 라고 안내된다.
- **한계**: 정수리 선이 위에서 3mm 라는 위치는 일반적인 배치를 보여 주는 **참고값**(민간 안내 기준)이며 공식 규정이 아니다. 얼굴 길이 3.2~3.6cm 가 핵심이다. 머리 길이 3.2~3.6cm 기준은 여권 규격으로 확인된 것이고 주민등록증에 같은 기준이 적용되는지는 확인하지 못했다. 제출처(외교부·구청·기관)의 **최신 규정을 꼭 확인**해야 한다. 앱은 얼굴을 자동으로 찾지 않는다(사람이 맞춘다).
- 구현: `web/src/tools/crop.js`(`GUIDES`, `guideLayout`, `drawGuide`), 검증 `web/tests/tools.unit.mjs` · `tests/e2e/crop_guide.cjs`.
