# 체형 보정 (다듬기 → 체형) — v2.0.0 · 경계 자동 맞춤 v2.1.0

## 목표
얼굴·몸 비율을 고치되 **배경이 일그러지지 않게**. 기존 리퀴파이는 사진 전체를 밀어서 배경 선이 휜다.

## 방식
1. **인물만 변형**: 올가미/브러시로 인물을 고르고, 변형은 "되돌려 찾기(backward mapping)"로 인물 픽셀과 *새 인물 마스크*를 만든다. 배경은 건드리지 않는다.
   - **폭**: 흰 선 두 줄 사이(위·아래 25% 구간은 부드럽게 0 → 가운데 1)에서 행마다 인물의 가로 중심을 기준으로 가로 배율(±15%).
   - **길이**: 밴드 안을 세로로 늘이거나 줄이고(±15%) 밴드 아래 내용은 따라 이동(위쪽은 고정).
   - **확대·축소**: 한 점 주변의 방사형 확대/축소(±40%) — 눈·코·턱 같은 작은 부분.
2. **드러난 배경 채우기**: (예전 인물 마스크 ∪ 새 인물 마스크)를 조금 키운 "바뀌는 곳"을 모르는 영역으로 보고, 바깥의 알려진 배경 색을 피라미드(push-pull)로 번지게 채운 뒤, 둘레 입자감과 같은 세기의 노이즈를 더한다. 인물이 커지는 쪽은 배경을 덮기만 한다.
3. **합성**: 결과 패치는 "바뀌는 곳"만 불투명, 나머지는 **완전 투명** → 레이어로 얹어도 그 밖의 배경은 한 픽셀도 바뀌지 않는다(단위 테스트·E2E 로 확인). 가장자리 2px 는 원본 색 그대로 번지게 섞는다.
4. **레이어**: 잠긴 이미지 레이어("체형 보정", `fx.kind = body`) — 숨기기·삭제·실행 취소·자동 복구. 여러 조절("이 조절 추가")을 쌓아 한 번에 적용한다. 도구를 나가면 미리보기는 버려지고 "적용"으로만 확정된다.

## 사용
다듬기 → 체형 → ① 인물 선택(몸 선을 따라 그리기) → ② 조절(폭/길이/확대·축소, 위·아래 선 · 강도) → 적용. 미리보기는 낮은 해상도로 실시간, 적용은 영역을 최대 1400px 로 다시 렌더해 계산한다.

## 인물 경계 자동 맞춤 (v2.1.0, `web/src/ai/autoselect.js`)
올가미를 **힌트**로 쓰고 실제 경계는 이미지가 정한다. 모델 파일 없이 오프라인으로 동작한다.
1. 올가미 안쪽 깊은 곳 = 확실한 인물, 바깥 깊은 곳 = 확실한 배경, **선 주변 띠(맞춤 범위, 긴 변의 1~10%, 기본 4%)** = 미확정.
2. 확실한 두 영역의 색 히스토그램(4비트·3비트 평균)으로 띠 픽셀의 인물/배경 점수를 매긴다. 올가미에서 멀수록 올가미 라벨을 선호하는 사전 확률을 더한다.
3. 이웃 픽셀 색차가 큰 곳(가장자리)에서 자르기 쉽게 8-이웃 가중치를 두고 **그래프 컷(Dinic 최대 흐름)** 으로 띠 전체를 한 번에 푼다. 480px 해상도에서 계산 후 선택 격자로 확대·부드럽게.
4. 작은 섬/구멍 정리. 결과가 올가미와 너무 다르거나(면적 50% 미만·160% 초과), 두 색 분포가 겹치면(인물·배경이 같은 색) **올가미 그대로** 쓰고 안내 토스트를 띄운다.
- 사용: 인물 선택 단계 → 올가미(기본 켜짐). 추가/빼기 모두 적용, 꺼짐 스위치와 맞춤 범위 슬라이더. 브러시는 자동 맞춤 없음. 선택 되돌리기로 한 번에 취소.
- **띠 밖은 건드리지 않는다**: 올가미가 몸에서 맞춤 범위보다 멀리 떨어진 곳(예: 머리 옆 빈 배경)은 그대로 선택된다 — 몸 선을 따라 대충 그리되 너무 크게 벗어나지 않게. 틀린 곳은 빼기/브러시로 고친다.
- 한계: 머리카락 끝·배경과 색이 비슷한 경계·그림자는 틀릴 수 있다. 자동 인물 분리(AI 모델)는 아니다.
- 테스트: `node web/tests/autoselect.unit.mjs`(13: 넉넉/파고듦/비뚤게/정확/색 구분 불가/경계 조건), `node tests/e2e/autoselect.cjs`(합성 인물 사진에서 느슨한 올가미 IoU 0.74 → 0.98, 꺼짐·되돌리기·빼기).

## 한계(솔직하게)
- **배경 채우기는 단순 배경(단색·그라데이션)에 가장 잘 맞는다.** 선·무늬·사람이 있는 배경에서는 채운 띠가 티 날 수 있다(무늬 이어붙이기·AI 채우기는 아직 없다). 너무 많이 줄이면(±15% 한도) 띠가 넓어져 더 티 난다.
- 인물 선택의 품질이 결과를 좌우한다 — 머리카락처럼 경계가 복잡하면 마스크를 손으로 다듬어야 한다. 경계 자동 맞춤은 색·가장자리 기반이라 AI 인물 분리가 아니다(용량·정확도).
- 몸이 자연스러운지(관절·옷 무늬 비율)는 사용자가 판단한다. 한 번에 크게 하지 말고 조금씩 쌓는 것을 권한다.
- 실기기에서 확인하지 못했다(합성 샘플 사진과 헤드리스 브라우저로만 검증). 큰 사진은 영역을 1400px 로 줄여 계산한다.
